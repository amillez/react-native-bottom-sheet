# Getting started

1. Install React Native Bottom Sheet and its portal peer,
   [`react-native-teleport`](https://github.com/kirillzyusko/react-native-teleport):

   ```sh
   npm i @swmansion/react-native-bottom-sheet react-native-teleport
   ```

2. Wrap your app with `BottomSheetProvider`:

   ```tsx
   const App = () => <BottomSheetProvider>{/* ... */}</BottomSheetProvider>;
   ```

   If your app already mounts teleport's `PortalProvider` above it, pass
   `renderPortalProvider={false}` so there is only one.

The library provides two components: `BottomSheet` (inline) and
`ModalBottomSheet` (modal). Both render their children as the sheet content,
with a `surface` prop for the background behind it, and are controlled via
`detents`, `index`, and `onIndexChange`. Use `onSettle` to observe when the
sheet finishes moving.
